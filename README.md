# DSA Assignment 2 – Organisational Hierarchy

## Objective

This assignment implements and analyses an organisational hierarchy using a general tree.

The program:

1. Constructs the given organisational hierarchy.
2. Displays the hierarchy using level-order traversal.
3. Stores department names in a searchable array.
4. Sorts the department names.
5. Compares Linear Search and Binary Search.
6. Records the number of comparisons for different search queries.
7. Analyses tree height, traversal behaviour and time/space complexity.
8. Determines the most suitable approach for organisational reporting and department searching.
